The bar

The real Palworld. A fresh critic is shown our capture beside an official Palworld frame — same shot type, same resolution, same format, labels stripped, order shuffled — and asked which one is the shipped commercial game. We are done when critics stop reliably picking correctly.

Biggest remaining gaps

  • Ground is 2–3× too dark relative to sky in every gameplay-framed shot (ratio 0.29–0.37 vs Palworld's 0.63–0.96). Ruled out by experiment: shadows, ambient, sun elevation, exposure. The terrain/grass albedo is too dark at the source.
  • The hero creature renders as a featureless white sphere at portrait distance — no face, ears, wool lobes, limbs or contact shadow — despite the HUD silhouette for the same species having all of them.
  • Depth of field is so strong the portrait background is mush; the reference keeps backgrounds legible but low-detail.
  • dusk_mood is nearly black (mean 40.6, std 7.8 — barely above the harness blank-frame threshold).
  • Reference gap: only 1 of 17 official stills is early-game peaceful exploration, so interaction_feed has no honest comp and is judged on the art-direction rubric instead.
  • Reference gap: the trailer never shows a creature noticing an approaching player, so behaviour_approach has no fair comp either and is graded against the 12 written aliveness criteria.

smoke — Scaffold, capture harness, blind-A/B tooling complete 2026-08-02
Engine, system contracts and the deterministic capture harness. The first run silently screenshotted the loading overlay and still reported OK — fixed, and a frame probe now fails any capture that is blank, uniform, or still showing an overlay.

Improvements landed

  • Fixed-timestep engine with a system registry; systems never import each other, so builder agents own disjoint directories without conflicts
  • Deterministic seeded RNG and noise — same seed always produces the same world, which is what makes round-over-round A/B meaningful
  • Headless capture harness driving the game through the same input path a human uses
  • Matched-shot protocol: 6 staged stills + 2 motion strips
  • Blind A/B pack builder that normalises resolution/format/quality so critics judge the picture, not a technical tell
  • 17 official Palworld stills + 60 trailer frames acquired, curated, and readable by agents

Gaps found by critics

  • Stub art across the board — this round only proved the measuring instruments work

Five rounds chasing the washed-out image. Honest outcome: r04, r05 and r06 are within 1% of each other on every tonal statistic — the last three rounds did not measurably change the picture. That plateau is what prompted switching from adjective-driven briefs to measured targets with hypotheses pre-eliminated by experiment.

Improvements landed

  • Overexposure from the earlier rounds was largely corrected — highlight clipping fell from 47% to 3.25%
  • Scene became genuinely content-rich: 8860 grass blades, 266 trees, 306 rocks, 14 creatures at 143–170 draw calls

Gaps found by critics

  • Three consecutive rounds produced no measurable change — the defect was never actually localised, only guessed at
  • The real cause (ground albedo, not exposure or shadows) went unidentified until it was isolated by controlled experiment

Two builders with hard numeric targets rather than adjectives. Look-dev owns the ground/sky ratio, saturation, clipping and the over-strong depth of field; the creature builder owns turning a blank white sphere back into something charming.
