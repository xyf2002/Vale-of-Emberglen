r07 — Fix the two measured dominant defects — both turned out to be real bugs complete 2026-08-02
Ground albedo and creature rendering, both diagnosed to root cause rather than tuned. Four compounding defects made the ground dark: a linear/sRGB colour-space error that multiplied terrain albedo by 0.36 before any light hit it; grass instance normals rotated near-horizontal by the inverse-transpose of a non-uniform blade scale; a dusk grade applying contrast around a pivot above the tone-mapped signal, driving every pixel negative; and wind amplitude in world metres laying blades over by 57 degrees. The creature was a blank sphere because src/creatures/index.js was still the STUB — all the real craft existed and was imported by nothing.

Improvements landed

  • Ground/sky luminance ratio 0.31 → 0.66–0.88, inside the reference band on all four priority shots
  • Highlight clipping 3.25% → 0.00%
  • Dusk mean luminance 40.6 → 52.6, against the reference night frame's 50.7
  • Creatures now render with wool lobes, oversized dark-tipped ears, upright horns, and a drawn face with iris and specular dot — the reference brief realised
  • Guardrails corrected against the reference instead of invented: the colour-count band was wrong, and ground/sky ratio is a daylight-only number so night shots are exempt rather than permanently flagged
  • Portrait staging fixed: the camera was placed at the player's ground height, which buried it inside any rising terrain — now each object is staged against the ground it actually stands on
  • Capture API exposes scene internals and groundAt(), so diagnostics measure the scene instead of arguing about it
  • tools/measure.py added: ground/sky ratio, saturation, clipping, palette width and local contrast against the real reference

Gaps found by critics

  • Local contrast is now the dominant measurable gap: 1.7–4.5 vs the reference 5.2–9.9
  • Blind A/B still 0/5 — the critic identified every frame, though the reasons shifted from gross exposure faults to specific material and composition problems
