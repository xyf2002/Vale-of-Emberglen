The bar

The real Palworld. A fresh critic is shown our capture beside an official Palworld frame — same shot type, same resolution, same format, labels stripped, order shuffled — and asked which one is the shipped commercial game. We are done when critics stop reliably picking correctly.

Biggest remaining gaps

  • Everything: the build is a stub baseline — noise terrain, capsule player, sphere creatures, flat lighting.
  • Reference gap: only 1 of 17 official stills is early-game peaceful exploration, so interaction_feed has no honest comp and is judged on the art-direction rubric instead.

Improvements landed

  • Fixed-timestep engine with a system registry; systems never import each other, so builder agents can own disjoint directories without conflicts
  • Deterministic seeded RNG and noise — same seed always produces the same world, which is what makes round-over-round A/B meaningful
  • Headless capture harness driving the game through the same input path a human uses
  • Matched-shot protocol: 6 staged stills + 2 motion strips
  • Blind A/B pack builder that normalises resolution/format/quality so critics judge the picture, not a technical tell
  • 17 official Palworld reference stills acquired and readable by agents
